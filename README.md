# 🧩 Reto Técnico — Gestión de Empleados y Departamentos

## 📖 Descripción
Este proyecto consiste en el desarrollo de una **API REST** para la **gestión de empleados y departamentos**.  
El sistema permite crear, visualizar, actualizar y eliminar empleados, relacionándolos con su respectivo departamento.  

El backend fue construido con **Node.js**, **Express** y **MongoDB**, y se implementará una interfaz visual en **HTML**, **CSS**, **Bootstrap** y **JavaScript** para consumir la API desde el frontend.

---

## 🛠️ Tecnologías utilizadas
### Backend:
- **Node.js**
- **Express**
- **MongoDB Atlas**
- **Mongoose**
- **dotenv**
- **cors**
- **Postman**
