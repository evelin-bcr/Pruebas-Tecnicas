# 🧩 Reto Técnico — Gestión de Empleados y Departamentos

## 📖 Descripción
Este proyecto es una aplicación web para la gestión de empleados y departamentos, que permite administrar la información del personal y su asignación a distintas áreas de la empresa. Incluye funcionalidades de creación, edición, eliminación y visualización de registros, con un diseño limpio y minimalista.

El backend fue construido con **Node.js**, **Express** y **MongoDB**, y se implementará una interfaz visual en **HTML**, **CSS**, **Bootstrap** y **JavaScript** para consumir la API desde el frontend.

---
